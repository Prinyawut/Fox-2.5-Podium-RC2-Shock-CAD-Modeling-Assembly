# Fox-2.5-Podium-RC2-Shock-CAD-Modeling-Assembly
SolidWorks CAD modeling and assembly of a Fox 2.5 Podium RC2 Front shock absorber for The Citadel Baja SAE team. The model was recreated from limited manufacturer-provided measurements because the manufacturer's CAD models were proprietary. Note: This is the design class project.
